## 2. 30 秒上手

```bash
# 1) 改代码：只改 /media/s/7A3A1DFD3A1DB6DB/REA
# 2) 同步到构建副本（只拷改动文件，别整树 rsync——会覆盖 local.properties 的 debug 签名配置）

# 3) 构建（只打手机/平板 arm64）
/home/s/build/container-run.sh /home/s/build/build-mobile-arm64.sh debug     # 检验包
/home/s/build/container-run.sh /home/s/build/build-mobile-arm64.sh release   # 发布包

# 4) 单测（按需 --tests 过滤，全量很慢）

# 5) 真机验证
adb install -r /home/s/REA-src/app/build/outputs/apk/mobileArm64_v8a/release/mobile-arm64_v8a.apk
```

**构建口径（2026-10-31 用户定）**：每次开发只打 **mobile（手机/平板）arm64-v8a** 一个包；leanback 与 armeabi-v7a **暂不构建**。发布物料、CNB 清单里仍保留四个变体的历史条目，但不再重新打包。

## 5. 关键约定（交接必读）

### 5.1 构建

- **只打 mobile arm64**：`/home/s/build/container-run.sh /home/s/build/build-mobile-arm64.sh [debug|release]`。
- 必须走容器 `hostroot:1`（宿主 `ulimit -v` 锁 4 GB，Gradle 起不来）；容器挂载**必须**含 `/usr/lib/locale:ro`（否则 assets 中文文件名导致 `mergeAssets` 报 `Invalid file path`）与 `/home/s/.android:/root/.android`（否则容器自建 debug keystore，装不上真机）。
- 一律加 `-PfastRelease=true`（关 R8/裁剪/lint）。
- 单测跑 `testMobileArm64_v8aDebugUnitTest`，可用 `--tests` 过滤（全量 11 分钟级）。
- 构建副本 `/home/s/REA-src/local.properties` 里有 4 行 debug 签名配置（真机检验包用），**不要提交、不要被整树同步覆盖**。

### 5.2 签名双轨

| 用途 | 签名 | 指纹 |
|---|---|---|
| 真机检验包 | `/home/s/.android/debug.keystore`（androiddebugkey/android） | `5bc08a3d…` |
| 发布包 | `/home/s/Android/secrets/webhtv-release.jks`（CN=WebHTV） | `5c3b6ccc…` |

装发布包前必须先卸载旧的（签名不一致不能覆盖）。

### 5.3 推送 GitHub（分叉历史专用）

远端与本地无共同祖先，**不要 force push**，用重放脚本：

```bash
bash /home/s/pub/replay-head.sh "提交说明"
```

原理：`--filter=blob:none --depth=1` 取远端提交树 → `read-tree/write-tree/commit-tree` 把本地树叠成新提交 → 只推增量 blob。
坑：下载侧仅 ~20 KB/s（上传 ~5 MB/s），全量 clone 336 MB 工作树不可行。

### 5.4 CNB 清单

```bash
git -c credential.helper='!cnb git-credential' push origin HEAD:main
```
（感叹号前缀不能少；`cnb` 在 `~/.workbuddy/binaries/node/cli-connector-packages/bin`，token 在 `~/.cnb/token`）

### 5.5 真机验证（用户明确要求：每轮做完直接 adb 操作验证，不要只出包）

1. **进入原生播放最可靠**：WebView 源的网页播放器不接管，用本地 server 推：
   ```bash
   adb forward tcp:19978 tcp:9978
   curl "http://127.0.0.1:19978/action?do=push&url=<urlencoded>"
   ```
   **推裸片名（如「庆余年」）会触发智能匹配**，直接变成正式播放页（站点+集数齐全），是弹幕测试的理想入口。
2. **全屏 `input tap` 坑**：全屏时点击会落到视频层（按钮点不到），且控件约 3 秒自动隐藏。可靠手法：先 `input tap 958 597` 点亮控件，**0.3~0.4 秒内**再点目标 chip。内联（详情页）模式坐标正常。
3. **中文输入坑**：`input text` 无法输入中文，关键词靠推送标题携带，再用 keyevent 修剪（`MOVE_HOME` 不可靠，用 DPAD_LEFT/RIGHT + DEL，边截图边核对）。
4. 截图实际是 1920×1200（工具里显示成 1080×675），坐标按 1.778 换算；底栏按钮 y≈1161~1163，y≥1178 会被手势区吞掉。
