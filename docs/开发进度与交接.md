## 3. 关键约定（交接必读）

### 3.1 构建

- 必须走容器 `hostroot:1`（宿主 `ulimit -v` 锁 4 GB）。
- 容器挂载**必须**含 `/usr/lib/locale:ro`（中文 assets 文件名）与 `/home/s/.android:/root/.android`（复用 debug keystore）。
- 一律 `-PfastRelease=true`（关 R8/裁剪/lint）。
- 构建副本 `local.properties` 有 4 行 debug 签名配置：**不提交、不被整树同步覆盖**。
- 构建耗时口径（2026-10-31 实测）：**增量构建约 3~4 分钟**（`build-mobile-arm64.sh debug` 实测 3m08s）；首次冷编译（含 Chaquopy 拉 Python 依赖、首次下载 Gradle 依赖）可能 20~30 分钟。写文档时请注明是冷编译还是增量。
- 单测全量约 11 分钟，按需 `--tests` 过滤（单类约 1.5 分钟）。

### 3.2 签名双轨

| 用途 | 签名 | 指纹 |
|---|---|---|
| 真机检验包 | `/home/s/.android/debug.keystore`（androiddebugkey/android） | `5bc08a3d…` |
| 发布包 | `/home/s/Android/secrets/webhtv-release.jks`（CN=WebHTV） | `5c3b6ccc…` |

装发布包前必须先卸载旧包（签名不一致不能覆盖）。未配置签名会静默退化为 debug 签名，发布前必须 `apksigner verify`。

### 3.4 真机验证

1. WebView 源网页播放器不接管，用本地 server 推：
   ```bash
   adb forward tcp:19978 tcp:9978
   curl "http://127.0.0.1:19978/action?do=push&url=<urlencoded>"
   ```
   推裸片名（如「庆余年」）会触发智能匹配，直接进正式播放页。
2. 全屏 `input tap` 先点 `958 597` 点亮控件，0.3~0.4 秒内再点目标（控件约 3 秒自动隐藏）。
3. `input text` 不支持中文，用 DPAD_LEFT/RIGHT + DEL 修剪。
4. 截图实际 1920×1200（工具显示 1080×675），坐标按 1.778 换算；底栏 y≈1161~1163，y≥1178 被手势区吞掉。
5. 平板模拟小屏：`wm size 1080x1920` + `wm density 480`；验证后 `reset`。

### 3.5 改代码前的同步检查

- 布局：四套 `activity_video.xml`（`layout` / `layout-land` / `layout-sw600dp` / `layout-sw600dp-land`）一起改。
- 文案：`values` / `values-zh-rCN` / `values-zh-rTW` 三份一起改。
- mobile 专属类不要移到 `main`，否则 leanback 编译失败。
- 新增 prefs 要登记 `Backup.APP_PREFS`，否则云备份/恢复丢配置。
