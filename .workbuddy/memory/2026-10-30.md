### 关键结论（别再踩）
- 扩展**存链接不存内容**：`WebHomeExtensionRegistry.loadRemote()` 会以该链接为 base 解析
  `"js": ["./xxx.js"]`，社区 manifest 清一色相对路径，存内容必然解析失败。
- registry 对「非 JSON 且是脚本 URL」有兜底，会自己包成 `{js:[url]}`，所以 `.js` 直链也能直接存。
- 扩展只对 **WebHome 站点**生效：`Item.site()` 里 `if (webHomeOnly && getExtensions()!=null)`，
  挂到通用 CSP 项上是静默无效的。
- `WebHomeExtensionDialog`（设置→增强功能→WebHome 扩展）**本来就有**链接源（`SOURCE_TYPE_LINK`），
  通道 B 不需要改，缺的只有站点注入这一路。

### 构建环境（重要）
- 宿主无 `java`/`javac`，JDK 在 `/home/s/Android/jdk21`，Gradle 必须跑在 `hostroot:1` 容器里。
- 容器内 **`/tmp` 不存在**，必须 `mkdir -p /tmp && chmod 1777 /tmp`，否则报
  「java.io.tmpdir is set to a directory that doesn't exist: /tmp」。
- chaquopy 要 **Python 3.10**，宿主只有 3.12；uv 装的在 `/home/s/.local/bin/python3.10`，
  必须挂 `/home/s/.local` 并加进 PATH，否则 `:chaquo:install...PythonRequirements` 失败。
- 首次冷编译约 28 分钟，`/usr/lib/locale` 与 `/home/s/.android` 必须挂（理由见 5.6.4 轮笔记）。
